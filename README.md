# JMFC Stats Dashboard

Google Apps Script 웹앱 소스 (`.../AKfycbyDj-.../exec`).

## 파일

| 파일 | GAS에 붙이는 이름 |
|------|------------------|
| `index_대시보드` / `deploy/index.html.txt` | `index` (HTML) |
| `code_대시보드` / `deploy/Code.gs.txt` | `Code.gs` |

Raw `.txt`를 열어 전체 복사 → Apps Script 에디터에 붙여넣기 → **새 버전 배포**.
